# Superstore Sales Dashboard

An interactive **Power BI Sales Dashboard** created to analyze sales,
profit, orders, margins, regional performance, product performance,
customer segments, and discount impact using the Superstore dataset.

## Project Files

  -----------------------------------------------------------------------
  File                                Description
  ----------------------------------- -----------------------------------
  `Superstore-Sales_Dashboard.pbix`   Power BI dashboard file

  `Superstore-Sales_Data.xlsx`        Source Excel dataset

  `Superstore-Sales_PPT.pdf`          PDF export/presentation of the
                                      dashboard
  -----------------------------------------------------------------------

## Dashboard Overview

The dashboard provides a consolidated view of business performance
through key performance indicators and interactive visualizations.

### Key Performance Indicators

-   **Total Sales:** 2.30M
-   **Total Profit:** 286.35K
-   **Total Orders:** 5,009
-   **Profit Margin:** 12%
-   **Average Order Value:** 459

> KPI values are based on the dashboard view shown in this project.

## Dashboard Analysis

The report includes the following analysis sections:

### 1. Category Profit & Margin Comparison

Compares sales, profit, and profit margin across major product
categories such as Technology, Office Supplies, and Furniture.

### 2. Profit by Sub-Category

Analyzes profit contribution from different sub-categories, including
Phones, Paper, Storage, Furnishings, Tables, and others.

### 3. Total Sales by Region

Shows sales performance across the Central, East, South, and West
regions.

### 4. Top 10 Products by Sales

Highlights the ten products generating the highest sales.

### 5. Total Sales by Segment

Compares sales across customer segments: - Consumer - Corporate - Home
Office

### 6. Total Profit by Discount Range

Analyzes how discount levels affect total profit and identifies discount
ranges associated with negative profitability.

### 7. Total Sales and Profits by Month

Shows monthly sales and profit trends to support performance and
seasonal analysis.

## Key Business Questions

This dashboard helps answer questions such as:

1.  Which category generates the highest sales and profit?
2.  Which sub-categories are profitable or loss-making?
3.  Which region contributes the most sales?
4.  Which products have the highest sales?
5.  Which customer segment generates the most revenue?
6.  How do discounts affect profitability?
7.  How do sales and profit change over time?

## How to Use

1.  Download or clone this repository.
2.  Open `Superstore-Sales_Dashboard.pbix` using Microsoft Power BI
    Desktop.
3.  If required, update the source path for
    `Superstore-Sales_Data.xlsx`.
4.  Use the region filters and dashboard visuals to explore the data.

## Project Objective

The objective of this project is to build an interactive business
intelligence dashboard that converts raw sales data into meaningful
insights for sales monitoring, profitability analysis, and business
decision-making.
